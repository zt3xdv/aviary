# API Reference

Base URL: `http://<agent-host>:8080/api/v1`

All endpoints except `/health` require authentication via Bearer token in the Authorization header.

## Authentication

```
Authorization: Bearer <TOKEN>
```

Tokens are Ed25519-signed binary tokens generated by the panel using its private key. The token contains:
- `panel_id` - panel identifier
- `issued_at` - Unix timestamp
- `expires_at` - Unix timestamp
- `nonce` - random 16 bytes

Generate tokens with the keygen tool:

```bash
go run cmd/keygen/main.go -token -panel-id "panel-1" -private-key panel_private.key -expiry 1h
```

## Error Format

All errors return JSON:

```json
{
  "error": "description of error"
}
```

Common status codes:
- 400 - bad request
- 401 - unauthorized (invalid or missing token)
- 403 - forbidden (IP not allowed)
- 404 - not found
- 500 - internal server error

## Endpoints

### Health Check

**GET** `/health`

No authentication required. Returns `{"status": "healthy"}` with 200 OK.

### Containers

#### List Containers

**GET** `/containers?all=true`

Query parameters:
- `all` - include stopped containers (default: false)

Response: array of container objects

```json

    "id": "abc123def456",
    "name": "web-server",
    "image": "nginx:latest",
    "state": "running",
    "status": "Up 2 hours",
    "created_at": "2024-01-15T10:30:00Z",
    "started_at": "2024-01-15T10:30:05Z",
    "labels": {"app": "web"},
    "ports": {"80/tcp": "0.0.0.0:8080"},
    "mounts": [],

      "memory_limit": 536870912,
      "cpu_limit": 1.0,
      "pids_limit": 100,
      "disk_limit": 10737418240
    }

```

#### Create Container

**POST** `/containers/create`

Request body:

```json
{
  "name": "my-container",
  "image": "nginx:latest",
  "cmd": ["nginx", "-g", "daemon off;"],
  "entrypoint": ["/docker-entrypoint.sh"],
  "env": ["ENV=value", "DEBUG=1"],
  "labels": {"app": "web", "version": "1.0"},
  "memory_mb": 512,
  "cpu_cores": 1.0,
  "pids_limit": 100,
  "disk_mb": 10240,
  "ports": {"80/tcp": "8080", "443/tcp": "8443"},
  "mounts": [
    {
      "type": "bind",
      "source": "/host/data",
      "target": "/data",
      "read_only": false,
      "propagation": "rprivate"
    },
    {
      "type": "volume",
      "source": "my-volume",
      "target": "/var/lib/data",
      "read_only": false
    }
  ],
  "network": "bridge",
  "restart": "unless-stopped",
  "read_only": false,
  "user": "1000:1000",
  "working_dir": "/app",
  "install_script": "#!/bin/bash\napt-get update && apt-get install -y curl"
}
```

All fields optional except `name` and `image`. Resource limits default to config values.

Response: 201 Created with container object.

#### Inspect Container

**GET** `/containers/{id}`

Returns full container details.

#### Container Actions

**POST** `/containers/{id}?action={action}`

Actions:
- `start` - start container
- `stop` - stop container (query: `timeout=30s`)
- `restart` - restart container (query: `timeout=30s`)
- `kill` - kill container (query: `signal=SIGKILL`)

Response: `{"status": "started"}` etc.

#### Remove Container

**DELETE** `/containers/{id}?force=true`

Query parameters:
- `force` - force remove running container (default: false)

Response: `{"status": "removed"}`

### Images

#### List Images

**GET** `/images`

Response: array of image objects.

#### Pull Image

**POST** `/images/pull`

Request body: `{"image": "nginx:latest"}`

Response: streaming JSON with pull progress.

#### Inspect Image

**GET** `/images/{id}`

Returns Docker ImageInspect response.

#### Remove Image

**DELETE** `/images/{id}`

Response: array of deleted/untagged objects.

### System

#### Docker Info

**GET** `/system/info`

Returns Docker Info JSON.

#### Docker Version

**GET** `/system/version`

Returns version information.

#### Disk Usage

**GET** `/system/df`

Returns disk usage for images, containers, volumes, build cache.

#### Prune System

**POST** `/system/prune`

Removes unused containers, images, networks, volumes. Returns space reclaimed.

### File Manager

All file operations are proxied through the agent to the in-container daemon. See [File Manager docs](file-manager.md) for full API.

**Base path:** `/api/v1/files/`

| Method | Path | Action | Description |
|--------|------|--------|-------------|
| GET | `/api/v1/files` | list | List directory (query: `path`, `container_id`) |
| GET | `/api/v1/files/<path>` | stat | File metadata (query: `action=stat`, `container_id`) |
| GET | `/api/v1/files/<path>` | read | Raw file content (query: `action=read` or `raw=true`, `container_id`) |
| POST | `/api/v1/files/<path>` | write | Write file (query: `action=write`, `container_id`, body: raw content) |
| POST | `/api/v1/files/<path>` | mkdir | Create directory (query: `action=mkdir`, `mode`, `container_id`) |
| POST | `/api/v1/files/<path>` | copy | Copy file/dir (query: `action=copy`, `dest`, `container_id`) |
| POST | `/api/v1/files/<path>/chmod` | chmod | Change permissions (query: `action=chmod`, `container_id`, body: `{"mode": 493}`) |
| PUT | `/api/v1/files/<path>` | move | Move/rename (query: `dest`, `container_id`) |
| POST | `/api/v1/files/<path>` | update | Update file (query: `action=update`, `container_id`, body: raw content) |
| DELETE | `/api/v1/files/<path>` | delete | Delete file/dir (query: `container_id`) |

**Process Management** (proxied to daemon):

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/files/process` | Get process info |
| POST | `/api/v1/files/process/start` | Start process |
| POST | `/api/v1/files/process/stop` | Stop process (query: `timeout`) |
| POST | `/api/v1/files/process/restart` | Restart process (query: `timeout`) |
| POST | `/api/v1/files/process/signal` | Send signal (body: `{"signal": "TERM"}`) |

All require `container_id` query parameter.
