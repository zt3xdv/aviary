# Configuration

The agent reads config from a YAML file. Path can be passed via `-config` flag or set with `AVIARY_CONFIG` env var. Default paths checked: `/etc/aviary/config.yaml`, `~/.config/aviary/config.yaml`, `./config.yaml`.

All settings can also be set via environment variables with `AVIARY_` prefix (e.g. `AVIARY_SERVER_PORT=9090`).

## Server

```yaml
server:
  address: "0.0.0.0"        # listen address
  port: 8080                # listen port
  read_timeout: "30s"       # HTTP read timeout
  write_timeout: "30s"      # HTTP write timeout
  idle_timeout: "120s"      # HTTP idle timeout
  tls:
    enabled: false          # enable HTTPS/WSS
    cert_file: ""           # path to cert file
    key_file: ""            # path to key file
```

## Docker

```yaml
docker:
  host: "unix:///var/run/docker.sock"  # Docker daemon socket (unix:// or tcp://)
  api_version: "1.44"                   # Docker API version
  timeout: "60s"                        # request timeout
  max_concurrent: 10                    # max concurrent operations
  default_memory_mb: 512                # default memory limit in MB
  default_cpu_cores: 1.0                # default CPU limit in cores (0.5, 1.0, 2.0, etc)
  default_pids: 100                     # default pids limit
  default_disk_mb: 10240                # default disk limit in MB (requires storage driver support)
  daemon_network: "aviary-network"      # REQUIRED: Docker network for agent↔daemon communication
```

Notes:
- Disk limit uses Docker storage opts (`size` parameter). Only works with storage drivers that support it (overlay2 with quota, devicemapper, etc).
- CPU cores is a float - 0.5 = half a core, 1.0 = one core, 2.0 = two cores.
- Memory and disk are in megabytes.
- **daemon_network is required** - the agent creates containers on this network and uses it to reach the in-container daemon. No auto-discovery fallback.

## Auth

```yaml
auth:
  panel_public_key: ""        # base64 Ed25519 public key (required)
  token_expiry: "1h"          # token validity duration
  allowed_ips: []             # list of allowed panel IPs/CIDRs (empty = allow all)
```

The public key is generated by the keygen tool and must match the panel's private key. IP allowlist supports CIDR notation (e.g. `10.0.0.0/8`, `192.168.1.100/32`).

## Metrics

```yaml
metrics:
  enabled: true               # enable /metrics endpoint
  address: "0.0.0.0"          # listen address
  port: 9090                  # listen port
  path: "/metrics"            # endpoint path
```

## Logging

```yaml
logging:
  level: "info"               # debug, info, warn, error
  format: "json"              # json or text
  output: "stdout"            # stdout, stderr, or file path
```

## Full Example

```yaml
server:
  address: "0.0.0.0"
  port: 8080
  read_timeout: "30s"
  write_timeout: "30s"
  idle_timeout: "120s"
  tls:
    enabled: false
    cert_file: ""
    key_file: ""

docker:
  host: "unix:///var/run/docker.sock"
  api_version: "1.44"
  timeout: "60s"
  max_concurrent: 10
  default_memory_mb: 512
  default_cpu_cores: 1.0
  default_pids: 100
  default_disk_mb: 10240
  daemon_network: "aviary-network"

auth:
  panel_public_key: "BASE64_ENCODED_PUBLIC_KEY"
  token_expiry: "1h"
  allowed_ips:
    - "10.0.0.0/8"
    - "192.168.1.100"

metrics:
  enabled: true
  address: "0.0.0.0"
  port: 9090
  path: "/metrics"

logging:
  level: "info"
  format: "json"
  output: "stdout"
```
